# CodeCraft AI Desktop - Windows Deployment Package

## 📁 Package Contents

This folder contains everything needed to run CodeCraft AI on Windows:

### Files:
- **CodeCraftAI.exe** - Main application executable (no admin rights needed)
- **start-codecraft-ai.bat** - Convenient launcher script
- **resources/** - Application resources and assets
- **README.txt** - This file

### Quick Start:
1. **Double-click** `CodeCraftAI.exe` to launch the application
2. **Or use** `start-codecraft-ai.bat` for guided launch
3. **No installation required** - runs immediately

## 🚀 System Requirements

- **Windows 10** or newer (64-bit recommended)
- **4GB RAM** minimum (8GB recommended) 
- **500MB** free disk space
- **Internet connection** for AI features (optional for offline tools)

## 📋 Usage Instructions

### First Launch:
1. **Extract** all files to a folder (if from ZIP)
2. **Double-click** CodeCraftAI.exe
3. **Allow** Windows Defender if prompted
4. **Start** using the tools immediately

### Daily Use:
- **Desktop Shortcut**: Copy CodeCraftAI.exe to Desktop
- **Start Menu**: Pin to Start for quick access  
- **Taskbar**: Pin to taskbar for convenience
- **USB Portable**: Copy entire folder to USB for mobility

### File Operations:
- **Open SQL Files**: File → Open SQL File (Ctrl+O)
- **Save Results**: File → Save SQL File (Ctrl+S)
- **New Project**: File → New Project (Ctrl+N)

### Tool Navigation:
- **SQL Converter**: Tools → SQL Converter (Ctrl+1)
- **ER Diagram**: Tools → ER Diagram Generator (Ctrl+2)
- **Code Generator**: Tools → Code Generator (Ctrl+3)
- **AI Chat**: Tools → AI Chat Assistant (Ctrl+4)

## 🛠️ Troubleshooting

### App Won't Start:
1. **Right-click** CodeCraftAI.exe → Properties → Unblock
2. **Add exception** in Windows Defender/Antivirus
3. **Try different folder** (Desktop, Documents)
4. **Check disk space** (need 500MB minimum)

### Performance Issues:
1. **Close other applications** to free RAM
2. **Check internet connection** for AI features
3. **Update Windows** to latest version
4. **Restart application** if it becomes slow

### Feature Not Working:
1. **Internet connection** required for AI tools
2. **Refresh** the application (Ctrl+R)
3. **Check backend connection** if using server features
4. **Try different AI provider** in settings
