## 🛠️ Troubleshooting Guide

### Common Issues & Solutions

**"Windows protected your PC" message:**
- Click "More info" → "Run anyway"
- Or: Right-click exe → Properties → Unblock

**Antivirus blocking application:**
- Add folder to antivirus exceptions
- Contact IT to whitelist application

**Slow performance:**
- Ensure 4GB+ RAM available
- Close other memory-intensive applications
- Check internet connection for AI features

**Network connectivity issues:**
- Verify corporate firewall allows outbound HTTPS
- AI features require internet, offline tools work
