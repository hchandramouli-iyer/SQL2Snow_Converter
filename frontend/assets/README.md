# CodeCraft AI Desktop App Icon

This directory contains the application icons for different platforms:

- icon.png (512x512) - Linux and fallback icon
- icon.ico - Windows icon 
- icon.icns - macOS icon

The icon represents the CodeCraft AI brand with a modern, professional design suitable for a development tool.

To generate platform-specific icons from a PNG source, you can use:
- electron-icon-builder
- Online icon converters
- macOS: `iconutil` command
- Windows: Various ICO generation tools
